# LIMIAR — Templo do Conflito

Uma experiência visual de fantasia sombria sobre a **Teoria dos Três Pietros**, baseada no conceito escolhido "04 — Templo do Conflito".

## Abrir

Abra `index.html` no navegador (Chrome, Edge, Firefox ou Safari). Todos os recursos são locais: sem servidor, conta ou conexão com a internet.

## Funcionalidades

- **Início:** arte do último conceito selecionado, com zonas clicáveis para acessar cada espectro.
- **Os três Pietros:** representação simbólica, tendências associadas, qualidades, riscos e perguntas de observação.
- **Gráfico vivo:** altar de três obeliscos em perspectiva 3D por CSS, ajuste separado de altura (influência) e espessura (intensidade), inclinação do centro, cenários ilustrativos e rotação por arrasto.
- **Rito simbólico:** cinco passagens de observação, com início e fim claros, sem invocações literais.
- **História:** linha do tempo aproximada baseada nos relatos, sem diagnósticos.
- **Atlas:** práticas de sustentação e cuidado.
- **Acessibilidade:** interface responsiva, navegação por teclado e opção para reduzir animações.

O site não gera PDF e não armazena automaticamente informações pessoais. O gráfico é uma expressão artística subjetiva, não uma medida psicológica. Os elementos tridimensionais são criados com CSS e perspectiva, não um jogo WebGL livre.

## Publicação GitHub Pages

Crie um repositório GitHub, como `limiar-atlas-interior`, e envie **index.html, README.md e a pasta assets/** para a raiz do repositório. Em **Settings → Pages**, escolha **Deploy from a branch → main → /(root)**. Aguarde o deploy.

O antigo LIMIAR e os modelos anteriores foram preservados em sua biblioteca, na pasta `/LIMIAR/Modelos anteriores`.
